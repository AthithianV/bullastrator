### How to start Desktop app

```bash
cd /home/athithian-dev/Desktop/bullastrator/bullastrator_ui
npm install
npm run tauri -- dev --config ../crates/bullastrator_desktop/tauri.conf.json
```

### How to build desktop app

```bash
npm run tauri -- build --config ../crates/bullastrator_desktop/tauri.conf.json
```
