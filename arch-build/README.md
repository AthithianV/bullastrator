# To Install Run

```bash
makepkg -si
```

Signature

```bash
tauri signer sign -k <path-to-your-private-key> ./path/to/bullastrator-0.1.0-1-x86_64.pkg.tar.zst
```

# To Install

```
sudo pacman -U bullastrator-0.1.0-1-x86_64.pkg.tar.zst
```

# To Unintall Run

```bash
sudo pacman -Rs bullastrator
```
